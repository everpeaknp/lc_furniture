# lc_furniture

Next.js 15 app using the App Router, React 19, TypeScript, and Tailwind CSS.

## Development

- `npm run dev` starts the Next.js development server.
- `npm run build` creates a production build.
- `npm run start` serves a production build.

## Project Structure

- `app/` contains routes, layouts, and global styles.
- `components/` contains shared UI components.
- `public/` contains static assets.
- `package.json` defines dependencies and scripts.
- `next.config.js` defines Next.js configuration.

Follow existing patterns in the relevant route or component. Keep changes scoped to the requested behavior and preserve existing styling conventions.
